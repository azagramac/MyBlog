# EverDrive GBA Mini

<figure><img src="../.gitbook/assets/image (172).png" alt="" width="375"><figcaption></figcaption></figure>

Latest firmware: [https://krikzz.com/pub/support/everdrive-gba/original-series/OS/](https://krikzz.com/pub/support/everdrive-gba/original-series/OS/)\
Store: [https://krikzz.com/our-products/cartridges/everdrive-gba-mini.html](https://krikzz.com/our-products/cartridges/everdrive-gba-mini.html)



**Specs:**<br>

* FPGA LATTICE iCE40HX1K-VQ100
* Logic Cells 1.280
* RAM4K Memory Blocks 16
* RAM4K RAM bits 64K

\
**Features:**<br>

* All save types supported, no ROM patching required
* Fast Loading (most games load within 1 - 2 seconds)
* Hard gold plating for cartridge contacts
* 256Mbit PSRAM (32MByte) ROM memory
* 1Mbit SRAM (128KByte) save memory
* Real-time clock support
* Low power consumption
* FAT32 support
* Supported with GameCube player, some revisions of Super Retro Advance adapter and other GBA accessories
* NES, GB and GBC ROM formats are support (emulation mode)
